## 一、可以写成论文的核心内容（三种组稿角度，可任选主线或组合）

**角度 A（方法论主线，推荐）**：一套"从现象到修复手段"的五步定位流程，应用于 FPGA 脉动阵列的
利用率分析——观察现象 → 统计图找规律 → 层级定位 → 修复手段映射 → 实验组验证。卖点：三层缺口
恰好各占 1/3、每层有独立的形状证据和独立的修复手段，结构干净，示范性强（第三节给出每步的对应产物）。

**角度 B（技术主线）**：INT8 脉动阵列在真实 VLA 推理负载下的利用率墙与成对杠杆——三层缺口分解、
四件修复手段（含编译器侧的相邻任务合并）、以及"计算侧修复与写通道整形必须成对实施"的帧账证明
（单独做任一件几乎无收益，成对做帧时间 −43%）。

**角度 C（负载刻画主线）**：真实 0.2B VLA 模型编译到 96 逻辑列阵列后的 GEMM 形状谱——深度双峰分布
（p50=257、p90=2049）、形状-利用率上限归因表、以及"深度 ≤64 的任务占 29% 时间只干 5.9% 的活"
这类负载特征如何决定微架构选择（拼段/拼列/不上大阵列）。

三种角度共用的硬核数字：利用率 26.5% → 68.7%（承诺口径）/ 72.8%（上界）；一帧 0.909 → 0.520 秒（−43%）；
写回 0.72 → 0.247 秒（−66%）。

## 五、公式与参数（可直接搬进论文，符号与脚本一致）

**架构参数**：48 物理列 × 16 行 = 768 DSP（B8 PE：Pack2 每物理列驻 2 逻辑列 × Pump2 核心时钟 2 倍）；
逻辑列 LC=96；峰值 PEAK=3072 MAC/接口拍；接口时钟 F=303.215 MHz；行组 ROWS=16。
校准系数 CAL_G = 336.44/319.99（GEMM 拍数模型→实测校准，a3 口径）。

**行组 tile 成本（现状）**：C_v0 = mt · max(k+2, DRAIN+DALIGN+2+wb(n,j0,y_tr))，其中 DRAIN=64、DALIGN=2；
wb = n（非转置）或 16·(跨到的 16 字行数)（转置）。喂数腿 k+2 与读出腿在接口时钟域串行取大——三层的根源。

**三层定义式**（tile 集合 T，|T|=80,633）：
- 排队层 L2 = Σ_T mt·max(0, 68+wb−(k+2)) × CAL_G
- 零头层 L3 = Σ_T C_v0·(1−n_sub/96) × CAL_G
- 喂数层 L1 = (G0 − ideal) − L2 − L3（残差）
- 校验：L1+L2+L3 = 136.1M = 缺口（脚本逐项打印）

**帧公式**：frame = max(comp, RD, WR) + θ；comp = G + COPY + ACTV = G + 50.3M；
RD = 20.1M（HP64 口径，(ctx+w)/64B）；WR ∈ {218.4 as-built 实测锚点, 74.3 r5_burst, 9.3 floor}；θ=40M。
每 M 拍 = 1/303.215 毫秒×1000 → 100M 拍 ≈ 0.33s。

**写腿三档**：as-built = rows×6（rows = st/16 = 37.1M）；merged = st/8 + Σ_store 2·ceil(len/2048)
= 74.3+0.6 = 74.9M；floor = st/64 = 9.3M（需写口加宽到 64B/拍）。

**修复件成本式**（逐件叠加）：
- 第 1 件（累加器乒乓）：C = mt·max(k+2, wb) + 68
- 第 2 件（写链 2×）：C = mt·max(k+2, wb/2) + 68
- 第 3 件（A 双 bank 2×）：C = mt·max(⌈k/2⌉+2, wb/2) + 68
- 第 4 件（编译器合并）：tile 集换为合并后 GEMM 集合（49,569→33,892）
- 拼浅段（上界）：k≤8 的 tile 按 8 段共享一次喂数计

## 六、口径与诚实边界（论文 limitation 素材）

1. **全部利用率/台阶/帧数字来自周期模型**。模型锚定三个帧级实测锚点（读 X=184.0、权重装载 V=108.1、
   写 W=218.4 M拍，a3 实测），写腿另有 −2% 交叉验证；但三层拆账与台阶**没有段级 RTL 实测背书**。
2. **72.8% 是上界**（拼浅段受写地板限制），承诺口径 68.7%。
3. **写回 0.247s 不含跳零收益**（保守）；含 0.81% 突发开销修正。
4. **16 位激活情景是一阶外推**，DSP 打包按乐观假设；decoder fp32 未单独拆。
5. 主频/功耗无综合数据（时序余量现状仅 +0.009ns，加电路的降频风险按 ≤2% 阈值管理）。
6. N-合并的"相邻 ≤8 条"是调度约束的保守近似；j0 取组首成员（对 wb 计算是毫米级近似）。
