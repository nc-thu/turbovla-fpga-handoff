4. 现在已经做成电路的部分

  • Pack2：16×48 物理阵列、96 逻辑列、INT8×INT8、INT32 累加、snapshot/readout、requant 和 INT8 写回。
  • 向量 primitive：Add、Mul、Bias、LayerNorm、Softmax、GELU、ReLU、Tanh、Exp、Div、Clamp 的有界整数接口。LayerNorm/Softmax 当前使用有界近似，不是 FP16 精确 IP。
  • 数据搬运和重排：CTX/WRAM 同步存储、DMA AXI 行为级通道、BMM 行缓存、transpose/gather/scatter/slice、9 点 im2col。
  • 模型尾部：action clamp、gripper 格式化和步号写入。

5. 还没有做成专用电路的部分

  • DINO/视觉 backbone：patch embedding、attention 的完整投影、归一化和大规模 feature 读写仍是 AUX/fallback；当前没有可综合的专用视觉 encoder。
  • T5/语言 encoder：文本 token embedding、完整 Transformer block、语言 KV/cache 尚未做成 RTL。embedding primitive 只覆盖接口位置和小表访问。
  • 复杂动态 attention：BMM 只有在两个操作数、布局和依赖都满足时才进入布局缓存；不能满足的 BMM 会保留 AUX 成本。
  • 精确 FP16 激活：tvla_fp16_activation_wrap 现在是注册的接口占位，尚未接入 Xilinx Floating-Point IP。当前整数 fallback 不能冒充 FP16 精度。
  • 完整的 bias/scale/采样链：不能整数融合的 bias、动态 scale、采样更新和动作前的复杂后处理还由编译器记录为 fallback。
  • 板级系统：本轮没有板级 DDR 控制器、NoC、真实 AXI 带宽测量、bitstream 下载和端到端 LIBERO 成功率复测。

7. 下一步建议

  1. 先把实现报告中的 Pack2 DSP、CTX/WRAM BRAM 和向量单元关键路径核对清楚。
  2. 为 LayerNorm、Softmax 和 GELU 接入实际 FP16 IP 或定点近似验证，分别测精度和时序。
  3. 按 trace 占比最高的 AUX 类别逐个拆出可综合模块，优先处理视觉投影、语言投影和动态 attention。
  4. 编译器增加“硬件已实现 / 行为级 / 软件 fallback”字段，防止后续报告把 unknown=0 误读成全硬件覆盖。

8. 证据边界

编译器统计是实际 trace 读取得到的结果；周期和吞吐是 Python 模型；RTL 是新 full-model top 的可综合集成；Vivado 资源和时序是综合/实现工具输出。没有 SAIF/VCD 时不报告 TOPS/W。没有真实训练权重完整 FPGA 回放时，不报告端到端模型延迟或成功率。
